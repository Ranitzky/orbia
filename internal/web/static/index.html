Einstellungen

Zugriff

Jeder mit Zugriff auf diese Adresse kann deine Bookmarks, App-Tokens und Einstellungen verwalten.

Linkding-Integrationen

Erstelle für jede App einen eigenen Token. Trage ihn zusammen mit dieser Orbia-Adresse in der App ein.

Aus Linkding importieren

Orbia übernimmt aktive und archivierte Bookmarks. Bei gleicher URL gelten die Daten aus Linkding.

HTTP überträgt den Token im lokalen Netz unverschlüsselt. Nutze HTTP nur in einem vertrauenswürdigen Netz. Öffentliche Ziele erfordern HTTPS.

Import & Export

HTML für Linkding und Browser. JSON sichert zusätzlich deine Dashboard-Seiten. Beim Import werden URLs zusammengeführt. Ein JSON-Backup ersetzt auch die Dashboard-Seiten.
